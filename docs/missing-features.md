# Κατάσταση Λειτουργιών

## Περίληψη

Το έγγραφο αυτό ενημερώθηκε μετά την ολοκλήρωση των βασικών ελλείψεων που είχαν εντοπιστεί στην εφαρμογή διαχείρισης συνταγών.

---

## Ολοκληρωμένες Λειτουργίες

### 1. Τροποποίηση και Διαγραφή Βημάτων

- Προστέθηκε backend συνάρτηση `update_step()` για τροποποίηση τίτλου, περιγραφής και διάρκειας βήματος.
- Προστέθηκε backend συνάρτηση `delete_step()` για διαγραφή μεμονωμένου βήματος.
- Μετά τη διαγραφή βήματος γίνεται αυτόματη αναρίθμηση των υπόλοιπων βημάτων της συνταγής.
- Το GUI επιτρέπει προσθήκη, επεξεργασία και διαγραφή βημάτων από το παράθυρο λεπτομερειών συνταγής.

### 2. Διαχείριση Υλικών

- Προστέθηκε backend συνάρτηση `remove_ingredient_from_recipe()` για αφαίρεση υλικού από συνταγή.
- Προστέθηκε backend συνάρτηση `remove_ingredient_from_step()` για αφαίρεση υλικού από συγκεκριμένο βήμα.
- Προστέθηκε backend συνάρτηση `replace_step_ingredients()` για ενημέρωση της λίστας υλικών ενός βήματος.
- Το GUI επιτρέπει προσθήκη και αφαίρεση υλικών από υπάρχουσα συνταγή.
- Το GUI επιτρέπει τροποποίηση υλικών σε κάθε βήμα μέσω της φόρμας επεξεργασίας βήματος.

### 3. Πλήρης Τροποποίηση Συνταγής μέσω GUI

- Το παράθυρο λεπτομερειών συνταγής δεν είναι πλέον μόνο για ανάγνωση.
- Ο χρήστης μπορεί να ενημερώσει βασικά στοιχεία, υλικά και βήματα.
- Ο χρήστης μπορεί να προσθέσει νέα βήματα σε υπάρχουσα συνταγή.
- Ο χρήστης μπορεί να διαγράψει μεμονωμένα βήματα από υπάρχουσα συνταγή.

- Ατομικές εκθέσεις 1-2 σελίδων σε PDF για κάθε μέλος.
